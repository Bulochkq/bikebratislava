# wp-theme — тема WordPress для Bike Bratislava

Ця папка існує **тільки в гілці `wordpress`**. У гілці `main` її немає — там живе
статичний сайт, який працює на бойовому домені.

## Що тут

`bikebratislava/` — власна тема WordPress. Це наш існуючий HTML, розрізаний на
шаблони. Дизайн і вся клієнтська логіка (модалки, конструктор турів, мобільна
панель, кукі-банер, фільтри журналу) переносяться без змін.

## Як цим користуватись

Тема розробляється локально через **Local** (WP Engine). Папку `bikebratislava/`
треба покласти або скопіювати в:

```
<папка Local-сайту>/app/public/wp-content/themes/bikebratislava/
```

Найзручніше — зробити символьне посилання, щоб правки в репозиторії одразу
було видно в локальному WordPress без копіювання.

## Правило безпеки

Статичні файли в корені репозиторію (`index.html`, `tours.html`, `contact.html`
та інші) **не чіпаємо**. Вони — робочий сайт і водночас еталон, з яким звіряємо
кожну сторінку теми. Видалити їх можна буде лише тоді, коли WordPress повністю
запрацює на бойовому домені.

## Порядок робіт

План перебудови — у файлі плану сесії. Коротко: спершу мінімальна тема з
головною сторінкою, потім спільні хедер і футер, збірка Tailwind, решта
сторінок, і аж потім типи записів для турів, гідів та журналу.
